# Reglas de Contexto para Redacción

**MANDATORIO:** Antes de redactar, reescribir o añadir cualquier tipo de texto en un documento, DEBES verificar siempre el contexto adyacente del archivo. NUNCA escribas o modifiques a ciegas basándote solo en el párrafo proporcionado por el usuario. 

1. Tienes que leer las líneas/secciones anteriores y posteriores usando las herramientas de lectura (`view_file` o `grep_search`).
2. Asegúrate de que tu modificación no introduce redundancias.
3. Asegúrate de que no haces referencias futuras a elementos que se explican inmediatamente después (o viceversa).
4. Mantén la coherencia absoluta con el flujo del documento.

**La orden principal es: LEER EL CONTEXTO ANTES DE REDACTAR.**
